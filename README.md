# 💫 About Me

I'm a backend-focused developer building scalable, production-grade systems with a strong emphasis on API design, database architecture, and system reliability.

Currently building a **Risk Management System** — designing the data models, REST APIs, and business logic layer from scratch. Previously shipped a **Task Management System** now in deployment, handling full CRUD lifecycle with authentication and role-based access control.

I'm looking to collaborate on backend-heavy projects — distributed systems, API platforms, or anything that involves solving real engineering problems at scale. If you're looking for a developer who cares about clean architecture and not just making things "work," let's connect.

Open to mentorship from engineers with experience in system design, database optimization, or cloud infrastructure.

---

## 🔧 What I Work On

- **API Development** — RESTful APIs with Express.js and FastAPI, JWT-based auth flows
- **Database Design** — PostgreSQL, MySQL, MongoDB; schema design and query optimization
- **ORM & Data Layers** — Prisma for type-safe DB access, Supabase for BaaS
- **Auth & Security** — JWT, session management, middleware pipelines
- **Cloud & Deployment** — AWS, Vercel, Render, Netlify
