# 💫 About Me

Backend developer focused on building and maintaining real systems, not just demos.

I’ve built and deployed internal tools currently used inside my company, including an **Invoice Generator** and a **Task Management System**. These systems handle authentication, role-based access control, background jobs, and database-driven workflows.

Right now I'm developing a **Risk Management System** where I’m responsible for designing the database schema, REST APIs, and service-layer logic. The first version is complete and ready for deployment, but the structure is being adjusted based on internal company requirements.

Most of what I know about backend development, deployment, and debugging production issues has been self-taught while working on real applications. When something breaks, I usually have to trace logs, inspect queries, and fix it under pressure — so staying calm and methodical during failures is something I’ve learned the hard way.

I'm interested in collaborating on backend-heavy projects involving APIs, databases, background processing, or infrastructure.

# 🔧 What I Work On

### Backend Systems
- Designing REST APIs using **Express.js** and **FastAPI**
- Implementing authentication flows with **JWT**
- Building **RBAC permission systems**
- Structuring service-layer architecture for maintainability

### Databases
- Schema design and migrations
- Query optimization and relational modeling
- Working with **PostgreSQL**, **MySQL**, and **MongoDB**

### Async Processing
- Background jobs using **Redis + BullMQ**
- Worker services for long-running tasks

### Infrastructure & Deployment
- Deploying services using **AWS**, **Render**, and **Vercel**
- Managing environment configuration and secrets
- Running Node services with process managers and containerized setups

### Debugging & Maintenance
- Investigating production issues
- Log analysis and error tracing
- Fixing performance bottlenecks and API failures
